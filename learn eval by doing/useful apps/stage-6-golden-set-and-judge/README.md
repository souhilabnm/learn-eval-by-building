# Stage 6: golden set and judge

## labeled-traces-viewer.html

Shows every field of a trace, including the PASS or FAIL label and the reason. Use it to see what a PASS and a FAIL look like before you label your own golden set.

1. Double-click `labeled-traces-viewer.html`.
2. Click Choose File and pick one of these from `recipe-chatbot\homeworks\hw3\reference_files`:
   - `labeled_traces.jsonl`: 101 traces labeled by hand, PASS or FAIL for following a diet.
   - `raw_traces.jsonl`: about 2,400 unlabeled traces.

It also opens your results file, or several trace files picked together (Ctrl+A or Shift+click in the file picker).

Read-only: your own labels go in your golden set sheet.

Copy of `recipe-chatbot/homeworks/hw3/reference_files/trace_viewer.html`.
