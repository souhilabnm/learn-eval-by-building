# Learn eval by building

My notes and playbook from learning how to build and evaluate AI agents, from zero, by doing: a guide, its templates and apps, and a working Recipe Chatbot to practise on.

**Read the guide online:** https://learn-eval-by-building.vercel.app

## Versions

Each version is its own branch. This `main` branch holds only this page.

| Version | Date | What it covers |
|---|---|---|
| [**v1.0**](https://github.com/souhilabnm/learn-eval-by-building/tree/v1.0) | November 2026 | Setup, stages 1–5 (spec, system prompt, test queries, traces, error analysis) and building search for the RAG (stage 6, points 1–3). [Changelog](https://github.com/souhilabnm/learn-eval-by-building/blob/v1.0/CHANGELOG.md) |

## Get started

In the Claude app: **Code** tab > new session > select a course folder (any name, any place). Type:

```
Clone the v1.0 branch of https://github.com/souhilabnm/learn-eval-by-building.git into this folder
```

Then follow the [v1.0 README](https://github.com/souhilabnm/learn-eval-by-building/tree/v1.0#readme) and the guide.
